## 🌸 About The Project

**Love For Her** is a personal romantic website designed to create a memorable digital experience for someone special.

This project combines modern web design concepts such as **glassmorphism**, **aurora background**, smooth animations, and interactive elements to deliver a cute and emotional storytelling experience.

The website is built from scratch using only:

- HTML5
- CSS3
- Vanilla JavaScript

No framework or external UI library is used.

---

# ✨ Features

## 🎬 Opening Cinematic
A beautiful opening animation that creates a cinematic first impression.

## 💕 Hero Section
A romantic landing section with:

- Animated text
- Gradient effects
- Floating hearts
- Aurora background

## ⌨️ Typewriter Effect
Dynamic text animation to display romantic messages.

## 🌷 About Her
A personal introduction section containing:

- Photo display
- Personal story
- Glassmorphism card design

## 🕰️ Timeline Story
A journey section that tells important moments and memories.

## ❤️ Love Counter
An animated counter showing how long the journey has been together.

## 📸 Memory Gallery
Interactive photo gallery with:

- Hover animation
- Smooth transition
- Responsive layout

## 💌 Love Letter
A digital love letter experience with elegant animations.

## 🎵 Music Player
Background music feature to enhance the romantic atmosphere.

## 💖 100 Reasons I Love You
A collection of reasons presented through beautiful animated cards.

## 🎉 Celebration Effects

Includes:

- Confetti animation
- Fireworks effect
- Ending surprise screen

# 🎨 Design Concept

The design follows:

### Cute Aesthetic
Soft colors, rounded elements, and romantic details.

### Pink Aesthetic
Using a warm pink palette to create a sweet atmosphere.

### Glassmorphism
Transparent cards with blur effects and soft shadows.

### Aurora Background
Animated gradients creating a dreamy environment.

### Mobile First
Optimized for:

- Smartphone
- Tablet
- Desktop
